# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта

Проект посвящён исследованию поведения пользователей Яндекс Афиши и факторов, связанных с повторными заказами.

Цель анализа - определить характеристики пользователей и заказов, которые связаны с более высокой покупательской активностью, и сформулировать рекомендации для работы с удержанием пользователей.

## Основные этапы

- получение данных из PostgreSQL с помощью SQL;
- предобработка данных;
- приведение выручки к единой валюте;
- формирование пользовательского профиля;
- исследовательский анализ данных;
- анализ повторных заказов;
- проверка исследовательских гипотез;
- анализ взаимосвязей с помощью коэффициента Phi_K;
- формулирование выводов и рекомендаций.

## Используемые технологии

- Python
- pandas
- matplotlib
- seaborn
- PostgreSQL
- SQLAlchemy
- Phi_K
- Jupyter Notebook

## Структура проекта

`Afisha Yandex Second Module Project.ipynb` - основной ноутбук с анализом.

`requirements.txt` - библиотеки, необходимые для запуска проекта.

`.env` используется для хранения параметров подключения к базе данных и не публикуется в репозитории.
